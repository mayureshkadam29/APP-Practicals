# Advance Python Practicals

This repository contains Python practicals demonstrating Object-Oriented Programming (OOP) concepts and problem-solving using Python.

# Practical 1: Library Management System

### Objective
Develop a Library Management System using OOP concepts.

#Features
- Add books
- Register patrons
- Borrow and return books
- Display book availability and borrowed records

# Concepts Used
- Classes & Objects
- Constructors
- Methods
- Lists
- Conditional Statements
